# 🚀 Website ONG ABBA

> Plataforma web institucional desenvolvida para a ONG ABBA, focada na apresentação da organização, projetos sociais e formulário de voluntariado/cadastro.

---

## 📌 Apresentação do Projeto

O **Website ONG ABBA** foi concebido com o objetivo de dar visibilidade às ações sociais da organização, facilitar o contacto com a comunidade e permitir o cadastro de novos apoiantes e voluntários.

### 💡 O que foi feito até agora:

Atualmente, o projeto encontra-se na fase de **Versão Final (Front-end)**. As seguintes etapas foram concluídas:

- [x] **Estruturação HTML5:** Criação das páginas institucionais com semântica correta.
- [x] **Página Inicial (`index.html`):** Apresentação da ONG e navegação principal.
- [x] **Página de Projetos (`projetos.html`):** Exibição das iniciativas e causas apoiadas.
- [x] **Página de Cadastro (`cadastro.html`):** Formulário para novos voluntários/membros.
- [x] **Estilização CSS3 (`style.css`):** Design responsivo e identidade visual padronizada.

---

## 🛠️ Tecnologias Utilizadas

Abaixo estão detalhadas as tecnologias utilizadas no desenvolvimento:

### 🎨 Front-end (Interface)
- **HTML5:** Estruturação semântica do conteúdo e formulários.
- **CSS3:** Estilização visual, layout e responsividade.

### 🛠️ Ferramentas
- **Git & GitHub:** Versionamento e hospedagem do código-fonte.
- **Visual Studio Code:** Ambiente de desenvolvimento.
